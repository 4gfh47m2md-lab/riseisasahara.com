01 — ストーリー自分のこと

2026年9月19日。

大学生のときに会社を立ち上げました。20歳でした。うまくはいきませんでしたが、そのときに身についたやり方を元に、できることを1つずつ増やしてきました。

起業で学んだ管理の仕組みを自分の成長のために使えば、ものすごい結果が出るのではないかと思い、会社を凍結させたあとは、自分の成長の仕組みを作り、実践しています。

やりたいのは、自分にしかできない仕事です。絵、英語、バスケットボール、テクノロジー。1つずつなら珍しくないものを掛け合わせて、自分だけのフィールドを作ります。

そこから、いろいろなものをこの世の中に生み出していきたいと思っています。このサイトは、その途中の記録です。

    実際にやってきた仕事だけ。それぞれ、いつ・どこでやったかを添えている。

    英語の指導

    英検・TOEIC・定期試験。中学生〜高校生、大人。個人指導は2017年から。2025年9月から Athlete Force で高校生の英語を担当。

    バスケットボールの指導（英語）

    幼稚園〜小学5年に英語で指導。2026年1月から幕張のインターナショナルスクールで週1回。

    通訳・英文の作成

    スポーツスクールでの通訳、英語の案内文・メール。Athlete Force、2025年9月〜。

    絵・イラスト

    鉛筆デッサン、水彩、アクリル、油彩、デジタル（Procreate・Adobe）。美術大学院（Illustration）修了。作品は /works/ に49点。

    デザイン

    イベントのフライヤー、SNS用の画像、LINE公式アカウントの配信デザイン。2020年から。

    ウェブサイトの制作

    1ページ完結のサイトを HTML と CSS で。公開（ドメイン・DNS）まで。このサイトが実例。

    Claude を使って、記録・集計・通知を自動で回す仕組みを作る。毎朝動く自動化25本と、前進ボード が実例。

    SNS運用代行（2022年〜）。2026年6月〜9月、株式会社Supernova Tokyo でアプリのマーケティング責任者。
